# تحلیل عمیق پروژه‌های Polaris-Void

> نویسنده: **Avatar** — ‏https://github.com/Polaris-Void
> تاریخ تحلیل: ۳۱ شهریور ۱۴۰۵ (سپتامبر ۲۰۲۶) — ۱۱ ریپوی عمومی، همه Batch/PowerShell، لایسنس Apache-2.0

---

## ۱. تصویر کلی اکوسیستم

| ویژگی | وضعیت |
|---|---|
| تعداد پروژه | ۱۱ ریپو، جمعاً ~۹۰KB اسکریپت (بدون احتساب آیکون) |
| زبان | ۱۰۰٪ Batch (`.bat`) + تکه‌های PowerShell + چند `.reg` |
| وابستگی خارجی | **صفر** — فقط ابزارهای داخلی ویندوز |
| سیستم‌عامل هدف | Windows 7 تا ۱۱ (بعضی عملاً ۱۰/۱۱) |
| مستندات | دوزبانه EN/FA با شیلد، مثال خروجی و دیسکلمر حقوقی کامل |
| الگوی ثابت | درخواست خودکار ادمین (UAC) + شمارش معکوس خروج + لاگ تمیز کنسول |

**فلسفه مشترک:** ابزارهای «یک‌کلیکه، قابل‌حمل، بدون نصب» که یک کار دقیق را با دستورات نیتیو ویندوز انجام می‌دهند. نویسنده به‌جای Python/EXE سراغ Batch رفته تا کاربر بتواند کد را بخواند و اعتماد کند — تصمیمی آگاهانه برای ابزارهای سطح سیستم.

---

## ۲. الگوهای معماری تکرارشونده (DNA مشترک)

1. **Self-Elevation:** هر اسکریپت حساس با `net session` / `fltmc` / `fsutil` سطح دسترسی را چک و با `powershell Start-Process -Verb RunAs` خودش را بالا می‌برد (همراه گارد ضدحلقه).
2. **موتور Robocopy:** برای هر کپی جدی (`/E /COPY:DAT /DCOPY:DAT /XJ /R:1 /W:1`) با خروجی ساکت.
3. **Registry به‌جای حدس:** خواندن `User Shell Folders` برای مسیر واقعی پوشه‌ها (سازگار با OneDrive و ریدایرکت).
4. **غیرمخرب بودن:** در بازیابی‌ها عمداً از `/MIR` و `/PURGE` استفاده نشده؛ فقط ادغام.
5. **Hybrid Batch+PowerShell:** منطق سنگین (هش، درخت، درایور) با یک‌لاینر PowerShell، پوسته و UX با Batch.
6. **UX کنسولی:** تم رنگی، هدر باکسی، شمارش معکوس بدون فریز (`timeout` + هرکلید).

## ۳. تحلیل تک‌تک پروژه‌ها

### ۱) Windows-No-Internet-Fix — مدیر NCSI و رفع «No Internet» کاذب ⭐ پرکاربردترین
- **فایل‌ها:** `Restart Network Service.bat` + دو `.reg` (فعال/غیرفعال‌کردن Active Probing)
- **تکنیک:** ست‌کردن `EnableActiveProbing` در `HKLM\...\NlaSvc\Parameters\Internet` + ری‌استارت `NlaSvc` (بدون ریبوت).
- **نقاط قوت:** حل ریشه‌ای آیکون کره/تعجب کاذب؛ کنترل تله‌متری `msftconnecttest.com`؛ سه فایل ۱۵۰ بایتی!
- **ریسک:** غیرفعال‌کردن پروبینگ یعنی ویندوز پورتال هتل/فرودگاه را تشخیص نمی‌دهد.
- **پیچیدگی:** ●○○○○

### ۲) Win-User-Backup — بکاپ/بازیابی پوشه‌های کاربر ⭐ مهندسی‌شده‌ترین
- **فایل‌ها:** `Backup.bat` (۶KB) + `Restore.bat` (۶.۸KB) → مقصد `C:\User Backup`
- **تکنیک کلیدی:** پارس رجیستری با ترفند «جداسازی روی نوع مقدار (`REG_SZ`)» تا نام‌های فاصله‌دار (`My Music`) نشکنند + زنجیره fallback (رجیستری ← پروفایل ← چهار مسیر OneDrive).
- **نقاط قوت:** ضد بازگشت (exclude خود مقصد و junctionها با `/XJ`)، retry کم‌تأخیر، صفر لاگ‌فایل، شمارش معکوس non-blocking.
- **محدودیت:** مقصد هاردکد `C:\` است (اگر ویندوز روی C نباشد یا فضا کم باشد مشکل)؛ از EFS/permission خاص بکاپ نمی‌گیرد (`/COPY:DAT` بدون `U`).
- **پیچیدگی:** ●●●●○

### ۳) Win-Spotlight-Icon-Toggle — حذف آیکون «Learn about this picture»
- **فایل‌ها:** دو `.reg` به‌کدینگ **UTF-16LE با BOM** (نکته فنی مهم برای بازتولید بایت‌به‌بایت).
- **تکنیک:** مقداردهی GUID آیکون Spotlight در `HKCU\...\HideDesktopIcons\NewStartPanel` (۱=مخفی).
- **نقاط قوت:** بدون نیاز به ادمین (HKCU)، بدون کشتن والپیپر؛ تمیزترین راه‌حل ممکن.
- **محدودیت:** گاهی نیاز به ری‌استارت Explorer دارد (در Cyber Toolkit دکمه‌اش گذاشته‌ایم).
- **پیچیدگی:** ●○○○○

### ۴) Win-Drv-Backup — بکاپ/بازیابی درایورهای OEM
- **تکنیک:** `dism /online /export-driver` برای خروجی + `pnputil /add-driver *.inf /subdirs /install` برای نصب گروهی → `‎%SystemDrive%\Backup_Driver`.
- **نقاط قوت:** صفر وابستگی؛ نجات‌دهنده واقعی قبل از تعویض ویندوز.
- **ریسک:** ری‌استور کور همه INFها روی سخت‌افزار متفاوت می‌تواند درایور اشتباه بنشاند؛ همیشه قبلش Restore Point بزن.
- **پیچیدگی:** ●●○○○

### ۵) Win-Display-Drv-Backup — بکاپ تخصصی درایور گرافیک
- **تکنیک:** فیلتر `Get-WindowsDriver -Online` روی GUID کلاس Display (`4d36e968-...`) و `ClassName -eq 'Display'` + خروجی تکی‌تکی با `pnputil /export-driver`.
- **نقاط قوت:** جراحی دقیق به‌جای بکاپ کور؛ کدهای خروج معنادار (۰/۱/۲)؛ مناسب گیمرها قبل از DDU.
- **محدودیت:** فقط درایورهای third-party (`oem*.inf`)؛ درایور اینباکس مایکروسافت را نمی‌گیرد.
- **پیچیدگی:** ●●●○○

### ۶) USB-Immunizer-Customizer — ایمن‌ساز و برندساز فلش
- **تکنیک:** ساخت فایل‌طعمه (`Android` و `System Volume Information !`) با اتریبیوت Hidden+System تا ویندوز/اندروید نتوانند پوشه هم‌نام بسازند + `autorun.inf` با آیکون و لیبل سفارشی.
- **نقاط قوت:** ایده هوشمندانه و قدیمیِ جواب‌پس‌داده؛ همراه آیکون اختصاصی ۳۴KB.
- **محدودیت:** روی فایل‌سیستم NTFS فلش و بعضی گوشی‌ها رفتار متفاوت است؛ `autorun.inf` در ویندوز مدرن فقط لیبل/آیکون می‌دهد (اجرا نه — که از نظر امنیتی خوب است).
- **پیچیدگی:** ●●○○○

### ۷) Reset-DNS-Proxy — کمک‌های اولیه شبکه
- **تکنیک:** `Set-DnsClientServerAddress -ResetServerAddresses` روی همه آداپترها + صفرکردن `ProxyEnable` در HKCU و HKLM + `ipconfig /flushdns`.
- **نقاط قوت:** پوشش ۸۰٪ مشکلات «وصلم ولی باز نمی‌شود» در یک دابل‌کلیک.
- **ریسک:** اگر کاربر عمداً DNS/پروکسی دستی (مثلاً شکن، merit، پروکسی سازمانی) دارد، پاک می‌شود — باید با آگاهی اجرا شود.
- **پیچیدگی:** ●●○○○

### ۸) Image-Video-Renamer — تغییرنام گروهی مدیا
- **تکنیک:** `for /r` بازگشتی روی ~۵۰ پسوند عکس و ~۴۰ پسوند ویدیو + سابروتین `ResolveUniqueName` برای suffix خودکار `(1)`، `(2)`... با سه تگ `[OK] [DUP] [FAIL]` و شمارنده.
- **نقاط قوت:** هیچ‌وقت بازنویسی/حذف نمی‌کند؛ گزارش جمع‌بندی تمیز.
- **نکته مهم:** فقط **پسوند** را عوض می‌کند (ترانسکد/انکد مجدد انجام نمی‌دهد) — برای هم‌نام‌سازی آرشیو عالی، برای تبدیل واقعی فرمت نه.
- **پیچیدگی:** ●●●○○

### ۹) Directory-Tree-Exporter — گزارش درختی + متادیتا
- **تکنیک:** هیبرید Batch+PowerShell: پیمایش بازگشتی با مرتب‌سازی (پوشه‌اول)، کاراکترهای باکس `├── └── │`، سایز human-readable، دو ستون تاریخ، جدول UTF-8 با پهنای داینامیک + محاسبه `Stopwatch`.
- **نقاط قوت:** خروجی واقعاً تمیز و آماده مستندسازی؛ لاگ خودش را exclude می‌کند؛ بدون ادمین.
- **پیچیدگی:** ●●●●○

### ۱۰) Directory-SHA256-Tree-Exporter — ممیزی SHA-256 ⭐ قدرتمندترین
- **تکنیک:** همان موتور (۹) + `Get-FileHash -Algorithm SHA256` برای تک‌تک فایل‌ها با `try/catch` (فایل قفل → تگ `<ACCESS DENIED>` بدون توقف اسکن).
- **نقاط قوت:** اثبات یکپارچگی/تشخیص دستکاری با ابزار نیتیو؛ مناسب تحویل پروژه و فارنزیک سبک.
- **محدودیت:** روی هزاران فایل بزرگ کُند می‌شود (طبیعیِ هش‌گیری)؛ هش پوشه ندارد (فقط فایل).
- **پیچیدگی:** ●●●●●

### ۱۱) Unpack-Subfolders — صاف‌کننده پوشه‌های تودرتو
- **تکنیک:** `for /r` + مقایسه `%%~dpF` با `%~dp0` + `move /y` + محافظت از خود اسکریپت (`%~f0`).
- **نقاط قوت:** ۷۱۷ بایت خالص و مؤثر؛ ایده‌آل بعد از اکسترکت آرشیو.
- **ریسک:** `move /y` یعنی **هم‌نام‌ها بی‌سروصدا بازنویسی می‌شوند** (برخلاف پروژه ۸ که suffix می‌زند) — تنها نقطه xkطرناک اکوسیستم؛ قبلش بکاپ بگیر.
- **پیچیدگی:** ●○○○○

## ۵. ارزیابی امنیتی (خلاصه مسئولانه)

- **مثبت:** سورس باز و خوانا، بدون دانلود/شبکه/EXE مشکوک، UAC استاندارد، بازیابی‌ها غیرمخرب.
- **احتیاط:** سه عملیات «نقطه بدون بازگشت» — ری‌استور کور درایور (۴)، ریست DNS/پروکسی دستی (۷)، و بازنویسی هم‌نام‌ها در Unpack (۱۱). در Cyber Toolkit این‌ها با لاگ هشدار اجرا می‌شوند.
- **توصیه:** همیشه قبل از ۴ و ۱۱ یک Restore Point یا کپی دستی بگیر.

## ۶. از تحلیل تا محصول: چه چیزی در Cyber Toolkit ساخته شد

| نیاز استخراج‌شده از تحلیل | پیاده‌سازی |
|---|---|
| هر ۱۱ ابزار، یک‌جا، بدون گشتن بین ریپوها | هاب واحد با ۱۱ ماژول + لینک مستقیم گیت‌هاب هرکدام |
| اسکریپت‌ها `%~dp0`محور بودند (باید داخل پوشه هدف کپی می‌شدند) | موتور **patch خودکار** `%~dp0` ← پوشه انتخابی + File Picker نیتیو |
| بایت‌به‌بایت بودن مهم بود (مخصوصاً REGهای UTF-16) | جاسازی **باینری خام** هر ۱۹ فایل + سلف‌تست یکپارچگی (۶۰+ چک سبز) |
| UAC تکراری آزاردهنده بود | خود اپ **بدون ادمین** بالا می‌آید؛ فقط اکشن‌های ادمین UAC می‌گیرند |
| کاربر نمی‌فهمید پشت صحنه چه می‌گذرد | **حالت تفکر**: لاگ عصبی مرحله‌به‌مرحله + مانیتور exit code زنده |
| توضیحات فقط انگلیسی بود | رابط **دوزبانه EN/FA** (نسخه Pro با سوییچ زنده) |

**نتیجه:** هر ۱۱ پروژه سالم، خوانا و خوش‌مستند هستند؛ باگ جدی پیدا نشد. Cyber Toolkit آن‌ها را از «۱۱ پوشه پراکنده» به «یک کنسول نئونی یک‌کلیکه» تبدیل می‌کند بدون اینکه حتی یک بایت از منطق اصلی عوض شود.
